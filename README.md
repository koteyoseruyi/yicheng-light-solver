# 方块翻转解答器

一个可以直接部署到 GitHub Pages 的静态网页，无需构建或安装依赖。本地预览时需要通过 HTTP 服务打开，因为浏览器通常不允许从 `file://` 页面加载 JavaScript 模块。

点击棋盘格，依次在空白、白色、黄色之间切换。点击“求解”后，页面显示应点击的坐标、棋盘编号和逐步预览。“重置棋盘”会清空输入。

也可以上传游戏截图，或在网页中按 Ctrl+V 粘贴剪贴板图片。网页在浏览器中根据白色和黄色方块自动定位棋盘并识别颜色，显示图片标注供核对，然后点击“填入棋盘”。如自动定位不准确，可点“调整定位”，再依次点击截图中左上角与右下角格子的中心。识别后的格子仍可手动修改。颜色识别主要针对与示例相近的游戏画面；方块很少、遮挡严重或画面颜色变化较大时需要人工核对。

求解器为非空格建立 GF(2) 线性方程，使用高斯消元判断有解性并取得特解与零空间基，然后对零空间做带下界剪枝的精确搜索，选取点击数最少的解。每格最多点击一次，因为点击两次会抵消。

## 发布到 GitHub Pages

将本目录中的 `index.html`、`styles.css`、`app.js`、`solver.js`、`recognition.js` 上传到 GitHub 仓库根目录，在仓库 **Settings → Pages → Build and deployment** 中选择 **Deploy from a branch**，指定主分支和 `/ (root)`。部署完成后即可通过 GitHub 提供的 `github.io` 链接访问。

如果本机安装了 Node.js，可在本目录运行 `npm test` 验证求解器。此命令仅用于测试，不是网站运行所必需。
